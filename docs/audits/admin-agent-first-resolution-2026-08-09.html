Operator Steps

  1. Open /admin and read the system health statement.
  2. Work the ordered Needs Attention queue. Each item names its owning agent and one next action.
  3. Use Run Atlas cycle for normal manual execution. A duplicate click returns the already-active cycle.
  4. If an active job must stop, use Cancel in Atlas. The job remains non-terminal until Modal confirms cancellation.
  5. If a stage fails, open that specialist agent and use only the repair action tied to the failure.
  6. Complete human review inside Knox. Routine fees do not require manual approval.
